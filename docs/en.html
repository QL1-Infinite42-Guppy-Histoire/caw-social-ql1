Wallet

Posting wallet

Posting, liking, Recaws and follows are signed inside this page by a small built-in wallet — the same way the Android app works. Getting a name (in the menu) uses your wallet app instead.

Use a separate wallet here, made only for CAW. Never type the recovery phrase of your main wallet.

The key is encrypted with your password and stored only in this browser. It is never sent anywhere.

If you clear this browser’s data, the wallet here is gone — it only comes back if you saved the recovery phrase.

Anyone who sees your recovery phrase owns this wallet. Keep it written down, offline, and private.

Get a name

Want to check a name first? Look up a name

Get a name

A name is how people find you on CAW, and once you get one it is yours for good. It costs qCAW — the price depends on the name and is shown before you pay anything — plus a tiny QOM fee for the record-keepers. You need a wallet app (such as MetaMask or FoxWallet) with qCAW in it.

Getting a name uses your wallet app — that is separate from the posting wallet in the menu, which is only for posting.

About this site

CAW is a social network where posts are kept on a shared public record (a blockchain) instead of one company's computers — so anyone can read them, and nobody can quietly rewrite them later.

This site is a community-made window into the QL1 version of CAW. It is not run by the official CAW team.

Add this page to your home screen and it opens like an app.

Posting — here, or in the app

On this web version you can read everything, get a name with your wallet app, and post with the built-in posting wallet — signing happens safely inside this page. The Android app works the same way.
